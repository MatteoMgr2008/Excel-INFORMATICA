# Excel - Informatica

🇮🇹 [Italiano](#-italiano) | 🇬🇧 [English](#-english)

## 🇮🇹 Italiano

### 📊 Descrizione
Raccolta di esercizi svolti in classe con **Microsoft Excel** per la materia **Informatica**. I fogli di calcolo servono per fare pratica con formule, riferimenti assoluti, funzioni (`SOMMA`, `MEDIA`), percentuali e grafici.

### 📁 Contenuto
Tutti i file si trovano nella cartella `Esercizi in classe/`.

| File | Descrizione |
|------|-------------|
| `Es. in classe.xlsx` | Primo esercizio con semplici formule aritmetiche tra celle. |
| `analisi.xlsx` | Analisi delle vendite di vini di un'azienda (anno 2002): conversione del prezzo Lire/Euro e calcolo del prezzo con IVA. |
| `vendite_vini.xlsx` | Versione estesa di `analisi.xlsx`: aggiunge incassi, totale e media delle vendite (`SOMMA`, `MEDIA`). |
| `vendite_abbigliamento.xlsx` | Vendite di un negozio di abbigliamento: incasso per articolo, percentuale di sconto, incidenza percentuale e totale. |
| `formule.xlsx` | Censimenti delle province lombarde (1931–1991): densità di popolazione, totali e incidenza sul totale. |
| `turisti_como.xlsx` | Distribuzione delle presenze turistiche nelle località del Lago di Como, con totali parziali e incidenze (riferimenti assoluti `$`). |
| `grafico_auto.xlsx` | Fatturato di vendita di automobili per marca (2009–2011) con totali e vari grafici (a torta, a barre, a linee, ad anello). |
| `pil.xlsx` | PIL nominale delle regioni italiane (2012–2014, in milioni di euro) con grafici a barre 3D e a linee. |

### 🛠️ Tecnologie
- **Microsoft Excel** (file `.xlsx`)

### ▶️ Come aprire i file
1. Clona o scarica il repository.
2. Apri i file `.xlsx` della cartella `Esercizi in classe/` con **Microsoft Excel** (oppure con un programma compatibile come LibreOffice Calc).

### 📋 Requisiti
- Microsoft Excel o un altro programma in grado di aprire file `.xlsx`.

## 🇬🇧 English

### 📊 Description
A collection of exercises done in class with **Microsoft Excel** for the **Computer Science** (Informatica) subject. The spreadsheets are used to practise formulas, absolute references, functions (`SUM`, `AVERAGE`), percentages and charts.

### 📁 Contents
All files are located in the `Esercizi in classe/` folder.

| File | Description |
|------|-------------|
| `Es. in classe.xlsx` | First exercise with simple arithmetic formulas between cells. |
| `analisi.xlsx` | Wine sales analysis for a company (year 2002): Lire/Euro price conversion and price including VAT. |
| `vendite_vini.xlsx` | Extended version of `analisi.xlsx`: adds revenue, total and average sales (`SUM`, `AVERAGE`). |
| `vendite_abbigliamento.xlsx` | Sales of a clothing shop: revenue per item, discount percentage, percentage share and total. |
| `formule.xlsx` | Census data for the Lombardy provinces (1931–1991): population density, totals and share of the total. |
| `turisti_como.xlsx` | Distribution of tourist stays across Lake Como towns, with subtotals and shares (absolute `$` references). |
| `grafico_auto.xlsx` | Car sales revenue by brand (2009–2011) with totals and several charts (pie, bar, line, doughnut). |
| `pil.xlsx` | Nominal GDP of the Italian regions (2012–2014, in millions of euros) with 3D bar and line charts. |

### 🛠️ Technologies
- **Microsoft Excel** (`.xlsx` files)

### ▶️ How to open the files
1. Clone or download the repository.
2. Open the `.xlsx` files in the `Esercizi in classe/` folder with **Microsoft Excel** (or a compatible program such as LibreOffice Calc).

### 📋 Requirements
- Microsoft Excel or any other program able to open `.xlsx` files.
